Cómo funciona

1. Selecciona PREASISTENCIA o ASISTENCIA REAL.
2. Escribe la actividad.
3. Pulsa INICIAR LECTOR.
4. Escanea el carnet.
5. El sistema identifica al jugador por Documento.
6. Registra automáticamente.
7. El lector queda listo para el siguiente carnet.
8. No permite duplicar el mismo registro.
